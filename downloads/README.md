# APK CareLink 2.2.0

`CareLink-2.2.0-debug.apk` est la compilation de développement livrée (signature et empreinte vérifiées), version 2.2.0-debug, identifiant Android `com.aistudio.cradlelink.vxrtw.debug`.

Sur GitHub, ouvrir l’APK puis cliquer sur **Download raw file** pour le télécharger. Le ZIP de cette branche contient également ce fichier.

Pour vérifier son intégrité après téléchargement, placer le fichier `.sha256` dans le même dossier et exécuter :

```sh
sha256sum -c CareLink-2.2.0-debug.apk.sha256
```

Installer cette même version sur les deux téléphones. Lire les [consignes d’installation et d’appairage](../README.md#installer-et-appairer) et les [conditions de validation](../docs/VALIDATION.md).

L’APK est signé avec une clé de développement ; cette clé privée n’est pas dans le dépôt. Ce fichier est une livraison d’essai, pas une version de production.
